## 🌟 Các Tính Năng Độc Quyền & Nổi Bật

### 1. ⚔️ Đấu Trường Code 1v1 (Speed Coding Arena PK)
- Thi đấu lập trình tốc độ trực tiếp với các AI Coder hoặc đối thủ theo thời gian thực.
- Đồng hồ LED đếm ngược kịch tính, thanh máu/tiến độ giải đề song song.
- Màn hình quan sát Radar đối thủ với mô phỏng gõ code và tỷ lệ vượt test case.
- Hệ thống xếp hạng điểm ELO đấu trường và vinh danh chiến thắng.

### 2. 🔍 Trực Quan Hóa Bộ Nhớ & Luồng Chạy (Memory & Call Stack Visualizer)
- Phân tích mã nguồn và trực quan hóa từng bước thực thi (Step-by-step debugger).
- Quan sát **Call Stack (Ngăn xếp hàm)** và **Variables Scope (Tên biến, kiểu dữ liệu int/float/str/list/bool và giá trị thực tế)** biến đổi qua từng dòng lệnh.
- Chế độ tự động chạy mượt mà (Auto-Play) hoặc tiến/lùi từng bước.

### 3. 🌐 Trình Thực Thi Đa Ngôn Ngữ Phía Client (Multi-Language Runner)
- **Python 3**: Chạy mã bằng động cơ Skulpt trực tiếp trên trình duyệt.
- **JavaScript (ES6+)**: Sandbox thực thi an toàn, bắt trọn `console.log` và đối tượng JSON.
- **HTML/CSS/Web**: Trình xem trước trực tiếp thời gian thực (**Live Preview iframe**).
- **C++ & Java**: Mô phỏng biên dịch và hiển thị output logic chính xác.
- **SQL Database**: Truy vấn bảng dữ liệu và kết quả dạng bảng dữ liệu tương tác.

### 4. 🎧 Góc Lofi Chill Lounge & Âm Thanh Phím Cơ Học
- Sử dụng **Web Audio API** tổng hợp âm thanh 100% offline không cần mạng:
  - ⌨️ **Tiếng gõ bàn phím cơ học (Mechanical Clicky switch)** chân thực khi bạn gõ code.
  - 🎧 Nhạc nền Lofi Chill Synthwave thư giãn khi debug.
  - 🌧️ Tiếng mưa rơi nhẹ (Gentle Rain) & ☕ Quán cà phê Cyber (Cyber Cafe).

### 5. 🤖 Trợ Lý AI Gia Sư Giọng Nói (AI Voice Mentor & Big-O Analyzer)
- Trợ lý AI phân tích lỗi, gợi ý thuật toán, chuyển đổi ngôn ngữ.
- **Nút "🔊 Đọc to"**: Phát âm giọng đọc tiếng Việt tự nhiên qua Web Speech API.
- **Nút "📥 Chèn vào Editor"**: 1-click đưa code chuẩn vào khung soạn thảo.
- **Nút "⚡ Phân tích Big-O"**: Đo lường độ phức tạp $O(N)$ và tiêu chuẩn Clean Code.

### 6. 👤 Quản Lý Hồ Sơ Cá Nhân & Biểu Đồ 365 Ngày (GitHub-style Heatmap)
- **Tải ảnh đại diện từ máy tính** (PNG, JPG, WebP) hoặc chọn từ **16 Avatar 3D Cyberpunk độc quyền**.
- **Biểu đồ đóng góp 365 ngày (Activity Heatmap)** ghi nhận lượt giải đề và streak học tập.
- Quản lý danh mục kỹ năng (Tags), hồ sơ GitHub, LinkedIn, ELO đấu trường và huy hiệu thành tích.

### 7. ⚙️ Tùy Chỉnh Toàn Diện (Settings)
- Bật/tắt chế độ Sáng / Tối (Dark / Light Theme).
- Tùy biến cỡ chữ trình soạn thảo (12px - 22px) và font chữ chuyên dụng (*Fira Code, JetBrains Mono...*).
- Âm thanh phản hồi tương tác (Audio Chimes).
- Cài đặt giờ nhắc nhở học tập hàng ngày qua Notification API.

## 🚀 Khởi Chạy Dự Án

### Yêu cầu:
- Node.js >= 18
- Trình duyệt hiện đại (Chrome, Edge, Firefox, Brave)

```bash
# 1. Cài đặt các gói phụ thuộc
npm install

# 2. Tạo file cấu hình môi trường
copy .env.example .env

# 3. Khởi chạy máy chủ phát triển
npm run dev
```

Mở trình duyệt tại **http://localhost:5173**.
